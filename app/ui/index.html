Model Optimizer

Makes a CS 1.6 server's downloads smaller: player-model animation packed or shared, and a .gz next to every file for fast download.

What to do

Pick a folder and press Optimize

Nothing in the folder you pick is changed: the tool writes an optimized copy to the output folder, checks every rewritten model against its original, and shows what clients would download before and after.

  1. Upload the output folder to your fast-download host (the .gz files next to the others).
  2. Put the same files on the game server.
  3. If animation was shared, add the files from shared_anims.txt to the server's resource list.
